## 阅读顺序

1. 先读《产品方向总纲》建立全局认知。
2. 要动手改手册，读《手册体验改版计划》。
3. 要起美食地图 / 后端，先读《架构方案》再动手。
4. 要铺分发与社群，读《增长与社群运营计划》。
