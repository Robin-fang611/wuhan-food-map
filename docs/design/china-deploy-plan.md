## 2. 推荐方案：国内轻量服务器 + IP 直连（免备案）

**原理**：备案只约束「域名解析到国内服务器 + 80/443 端口」。**直接用 IP + 非标准端口访问不需要备案**。

- **后端**：Node 跑在 `http://<服务器IP>:8799`
- **前端**：静态文件用 nginx 跑在 `http://<服务器IP>:8080`（非 80 端口 → 免备案）
- 用户访问：`http://<IP>:8080`（分享时给二维码/短链）

> 注册路径：腾讯云 https://cloud.tencent.com → 轻量应用服务器 → 新用户活动/免费试用（需实名，手机号即可）

### 一键部署（服务器上执行，无需 flyctl/docker）

服务器拿到后，把仓库代码放上去（git clone 或 rsync），执行：
```bash
bash deploy/china-setup.sh
```
脚本自动：装 Node 22 + pm2 → 配 .env → 起后端(:8799) → 起前端静态服务(:8080) → 输出访问地址。
