## R1 服务器 —— 后端要 7×24 在线

**价值**：蛮有味后端（Node :8799）承载 /run 双轨智能体、/agent LLM、账号、收藏、券、探店采集。本地电脑一关机，所有用户的服务就没了。前端静态资源也需要公网托管才能分享链接。

**实现方式（免费优先）**：

| 方案 | 成本 | 优点 | 缺点 |
|------|------|------|------|
| **A. Fly.io 免费层** | 0 | 3 台共享实例（256MB RAM）免费用；`fly deploy` 一条命令；海外免备案 | 国内访问延迟 100–200ms（Demo 可接受）；内存小（我们 Node 进程 ~100MB，够） |
| **B. Render 免费层** | 0 | 免费 Web Service（750h/月，够一个实例常开）；自动 HTTPS | 同上海外；免费实例闲置 15 分钟休眠（唤醒 30s）——可配 cron 保活 |
| **C. Cloudflare Tunnel + 任意电脑** | 0 | 你 Mac/旧电脑跑 Node + cloudflared（免费），内网穿透到公网域名；免备案 | 依赖设备开机；家庭宽带断电即断 |
| **D. 腾讯云/阿里云轻量** | ~¥10–50/月 | 国内直连快；学生/新用户优惠（部分 3–6 个月免费试用） | 需实名 + 国内服务器需备案（R2） |
| **E. Serverless 改造** | 0–¥ | Vercel Functions / Cloudflare Workers | **不推荐**：我们是有状态服务（文件存储账号/收藏/券），改造需换外部存储，工作量大 |

**推荐**：Demo 先用 **A（Fly.io）**——免费、免备案、一条命令部署；有真实用户后再迁国内（D）。

## R2 域名 + 备案 —— 分享入口与登录回调

**价值**：① 用户记住与分享的入口（manyouwei.com vs IP 长串）；② 微信登录回调**必须** HTTPS 域名；③ 安全（CORS 白名单、cookie 域）。**备案**是国内服务器解析的强制要求（不备案 80/443 被拦截），海外托管免备案。

**实现方式（免费优先）**：

| 方案 | 成本 | 说明 |
|------|------|------|
| **A. Vercel/Fly 免费子域** | 0 | `xxx.vercel.app` / `xxx.fly.dev`，零配置 HTTPS——**Demo 完全够用** |
| **B. 便宜付费域名** | ~¥10–70/年 | Namecheap .xyz/.top 首年 ~¥10；阿里云 .com 新用户 ~¥55/年。绑定 Cloudflare DNS（免费 CDN+HTTPS） |
| **C. 备案** | 0（但需 1–2 周） | 仅当用国内服务器时需要：实名 + 域名 + 阿里云/腾讯云备案流程 |
| ~~D. Freenom 免费域名~~ | ~~0~~ | **不推荐**：.tk/.ml 稳定性差、易被回收 |

**关键结论**：**Demo 阶段用免费子域，完全不需要买域名、不需要备案**。微信登录（要求备案域名）与域名购买一起放到正式运营阶段。

## R3 短信 —— 登录闭环的安全通道

**价值**：短信验证码是"手机号属于你"的证明，是登录的安全基础（防止撞库/盗号）。当前 `SMS_PROVIDER=console` 只能在开发环境打印验证码，**上线后用户收不到真实短信就无法登录**——产品核心功能。

**实现方式（免费优先）**：

| 阶段 | 方案 | 成本 |
|------|------|------|
| **内测/Demo（现在）** | `SMS_PROVIDER=console`：后端在日志打印验证码，前端开发模式显示 devCode——**0 元**，功能全通 | 0 |
| 封闭邀请测试 | 固定 devCode 模式（后端配置）或小范围发码 | 0 |
| **正式发布** | 腾讯云短信：注册（实名免费）→ 申请签名 + 模板（**审核免费**）→ 按条计费 ~¥0.04/条。100 用户 × 3 条 ≈ **¥12** | ~¥12 |
| 备选 | 阿里云短信（新用户常送试用条数）；各类短信平台体验包 | 0–¥20 |

**结论**：短信**没有真正免费**的（都按条计费），但成本极低（¥10-20 能用很久）。Demo 阶段 0 元用 console 模式，正式发布前再开通。

## R4 微信登录 —— 最顺滑的校园登录

**价值**：校园用户几乎人人微信，微信内置浏览器打开即授权登录，零输入；且微信登录是后续"分享到微信/群"裂变的信任基础。

**实现方式（诚实说明：无免费路径）**：
- 微信开放平台（open.weixin.qq.com）注册需 **¥300/年** 认证费；
- 公众号网页授权需认证的服务号/订阅号（同样 ¥300/年）；
- 我们代码已完全就绪（`/auth/wechat/*` 端点 + 前端微信按钮），**只差凭据**——配置即启用。

**推荐**：**Demo 阶段不做微信登录**（手机号登录已够用），¥300 等产品有真实用户/营收信号后再投入。代码零改动，届时填 3 个 env 即启用。
