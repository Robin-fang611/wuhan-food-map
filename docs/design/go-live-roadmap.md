## 3. 工作流分期（W0–W9）

> 每期：实现 → 测试 → 审阅 → 推送；「需 Robin」= 等决策/凭据。

### W0 前置（✅ 已完成 2026-08-15）
SPEC §15 反馈清单、双轨方案、界面重构设计、视觉桥接工具（实测可用）、智谱 Key 入 .env（gitignored）。

### W1 双轨引擎（= dual-track P1–P4）
算法层增强（FIT 健康语义/店名检索优先/口味约束筛选/诚实回落）→ 路由判定 shouldUpgrade + /run 升级接入 → 智能体适配（纪律 v2 + finalize note）→ 前端统一推演（渐进点亮 + 无来源标签）。
**验收**：「清淡的健身餐」实事求是；「老樊城」精准；升级/降级双路径实测；新增单测 ≥30 断言。

### W2 界面重构（= dual-track P5 + 界面设计 P1）
底部 4 Tab（今天吃啥/附近地图/我的/福利）；首页收敛为对话 + 回顾 + 本地速览；商业化模块全部迁入福利 Tab；推理页渐进式推演（与 W1 联动）。
**验收**：首页无签到/抽奖/任务字样；福利 Tab 全功能可用；测试全绿。

### W3 数据真实化（上线命门，部分需 Robin 实地）
- W3.1 南湖坐标补全：127 家缺坐标批量 geocode（高德服务端 Key 已有）→ 人工抽查 20% → 南湖 ≥150/185（**我可立即做**）
- W3.2 流动摊坐标众包：206 家 0 坐标 → 覆盖财大小吃街核心摊（上传定位 + 视觉识别辅助）
- W3.3 首批真实探店：30–50 家财大周边 estimated→verified（collect-visit.mjs 就绪，**需 Robin 实地**，可并行）
- W3.4 商家照片：探店拍照入库（Demo 有图）
**验收**：南湖坐标 ≥150；流动摊核心区有坐标；verified ≥70；地图「摊」标可见。

### W4 注册与验证码生产化（需 Robin 凭据）
**注册流程完整化**：
- 注册 = 协议/隐私同意（勾选必填，存同意记录）→ 图形验证码 → 短信验证码 → 登录 → 首登引导设置昵称
- 账号生命周期：**注销账号**（删用户 + 收藏 + 券 + 上传记录，合规必需）、登出即吊销会话
- 会话管理：JWT 加 refresh/续期机制 + token 吊销（登出/注销/异常时失效），不再 30 天裸 token
**验证码生产化**：
- 短信网关：SMS_PROVIDER=tencent + 密钥（**需 Robin**）+ **短信签名/模板备案**（腾讯云审核，提前启动）
- 频控升级：手机号级（已有）+ **IP 级**（1 小时 ≤20 等）+ 设备指纹可选
- 验证码发送审计日志（不落验证码本身）
- 图形验证码保留；行为验证（滑动拼图）作为上线后升级项
**验收**：真实短信收码登录成功；连续错误/高频触发 IP 拦截；注销后数据删除且 token 失效；协议同意不可跳过。

### W5 安全防护加固（纯代码，W4 之前可先行）
1. **写操作全 JWT 化**：checkin / claim / view-wallet 从「信任客户端 userId」改为「服务端从 JWT 解析 sub」（S4 只做了 favorite，**其余 3 个写工具必须补**）+ 前端 agent-client 相应传 Authorization
2. **CORS 白名单**：生产仅允许前端域名（FRONTEND_ORIGIN 白名单），弃用 `*`
3. **全局限流**：IP 维度（如 60 req/min）+ 接口维度（登录/短信/上传/LLM 升级各自限流）；LLM 升级按用户/IP 限流（防成本被刷爆）
4. **治理接口鉴权**：/upload/govern、/upload/pending 加管理员令牌（env ADMIN_TOKEN 或 JWT 角色）
5. **输入加固**：请求体大小上限（如 1MB）、JSON 解析异常处理、字段长度/类型白名单
6. **数据安全**：手机号落盘加密（AES，密钥 env）或最小化（hash 索引 + 密文）；日志脱敏（不打印手机号/验证码/密钥）；生产错误响应不泄露内部路径/堆栈
7. **依赖安全**：npm audit 清零或记录已知项
8. **上传安全**：图片/内容校验（类型/大小/危险内容扫描可选）
**验收**：越权渗透自查（改别人 userId 读券/签到 → 全拒）；IP 刷接口被限流；CORS 非白名单域名被拒；治理接口无令牌 401；LLM 升级超限被拦；红线扫描 0 命中。

### W6 商业化生产化
福利 Tab 全链路验收（签到/抽奖/任务/券包/核销）；演示核销模式（无真实商家 → 内置演示商户，Demo 现场完整走 领券→到店→核销）。
**验收**：福利 Tab 每模块可用；演示核销闭环可走通。

### W7 部署上线（需 Robin 决策服务器/域名）
后端部署（国内云 VPS/轻量；**备案决策**：国内域名备案周期 1–2 周，建议最早启动）；域名 + HTTPS；存储 文件→SQLite（参数化查询）+ 备份策略；进程守护（pm2/systemd）+ 日志轮转；监控（前端错误上报、访问量 tongji、后端错误日志、**LLM 调用量/成本日志**）；前端接生产 API（VITE_API_BASE）。
**验收**：新装环境一键部署脚本可复现；重启数据不丢；HTTPS 生效；监控可见。

### W8 内容运营 + 全量验收
冷启动内容（首页「今天附近」精选 3–5 条）；新用户引导（选口味→问一次→收藏）；分享路径（卡片图 + 文案，AI 基础版，logo 需 Robin）；隐私说明页上线（W4 协议联动）。
**验收**：D1–D10 全过；输出验收报告（真机/性能/安全/合规四项）。

### W9 灰度发布
50–100 名校园用户跑 1–2 周；看板核对（DAU/决策完成率/收藏率/复访）；反馈进 SPEC §15 → 修关键 bug → Demo 正式发布。
**验收**：周留存数据出炉；关键 bug 清零。
