## 1. 一句话与定位

**蛮有味 = 武汉（校园先行）的 AI 美食发现 Agent。**

> 「今天吃啥？问蛮有味。」—— 你说一句偏好（心情 / 预算 / 和谁吃 / 片区），它给你**一个主推 + 2~3 备选，每家都带为什么**，而不是甩一张长列表。

- **核心 Job**：帮学生快速决定「今天吃啥」（高频、低介入、怕踩雷）。
- **信任内核**：推荐排序永不被商户付费/分润影响（可审计）——这是与大众点评/美团最根本的差异。
- **实事求是**：没有合适的店铺就直说没有，绝不硬凑；「健身餐」这类无数据覆盖的需求会诚实标注。
- **本地生活**：小吃街、流动摊贩（206 家高德上没有的数据资产）是差异化护城河。

## 2. 用户与场景

- **主用户**：财大南湖周边学生（大一、大二为主）、周边食客。
- **典型场景**：
  - 「心情不好想吃点治愈系暖暖的」→ 情境推荐
  - 「清淡的健身餐，低脂高蛋白」→ 健康语义 + 实事求是
  - 「老樊城」「蔡林记」→ 直接店名检索
  - 「南湖附近便宜的宵夜」→ 结构化筛选（片区+时段+预算）
  - 「换一家 / 再便宜点 / 换个附近」→ 多轮追问（真实生效）

## 3. 产品功能全景（2026-08-15 当前版本）

### 3.1 界面结构（底部 4 Tab）

| Tab | 内容 |
|-----|------|
| 🍜 **今天吃啥** | 对话入口（输入框 + 情境 chips）+ 上次推荐回顾 + 本地生活速览（财大南湖 185 家） |
| 🗺 **附近** | 地图（流动摊紫色「摊」标）+ 上传店铺入口 + 商户详情 |
| 🧾 **我的** | 登录 / 账号（昵称编辑、注销）/ 我的收藏 |
| 🎁 **福利** | 每日签到 / 幸运抽奖 / 新人任务 / 我的券包 / 演示核销（商业化集中地） |

### 3.2 智能体推荐流程（核心体验）

```
用户输入 → ①理解意图 → ②检索数据库 → ③匹配条件 → ④排序权衡 → ⑤生成推荐（渐进点亮展示）
          ↓ 搞不定的自动升级
          DeepSeek 深度分析（前端无感，同一套推演展示）
```

- 结果：1 主推 + 2~3 备选，每家带「为什么推荐」（因子权重条）+ 一键导航（高德公开链接）+ 可收藏。
- 每次回复后可多轮追问（换一家/再便宜点/换个附近/收藏这家）。
- 无匹配时诚实空态（「数据库没有符合要求的店铺」）。

### 3.3 账号（2026-08-15 决策：简化登录）

- **登录方式**：手机号 + 图形验证码（人机验证）直接登录——**Demo 阶段不做短信验证码、不做微信登录**（后置，见决策记录）。
- 协议同意必填（《用户协议与隐私政策》页面已上线，#privacy）。
- 账号能力：昵称编辑、收藏跨设备同步、**注销账号（删除全部数据）**、登出吊销会话。
- 手机号加密存储（AES-256-GCM）+ 索引哈希化。

## 4. 探店（2026-08-15 升级为用户众包功能）

**探店 = 用户（或创始人）实地去过一家店后，提交真实信息，把数据从「算法推测」升级为「实地核验」。**

**产品内众包闭环（已上线）**：
- 详情页「资料待核验」的店 → **「你去过这家？来探店补全数据」面板**：评分（必吃/推荐/一般）+ 推荐菜 + 人均 + 口味 + 备注 + **真实承诺勾选** → 提交（登录态）。
- 后端校验（JWT 身份 / attest 承诺 / 每用户每天 ≤10 条 / 同店去重）→ 待审核。
- 管理员审核（ADMIN_TOKEN）→ 通过后**自动合并进数据管线**（enrichment-explore.json → normalize 重生成 merchants.js → 该店升级为 verified，来源标注 user-explore）。
- 创始人批量工具 `collect-visit.mjs` 保留（可高效补全 500+ 家：清单见 `docs/visit-list-2026-08-15.md`，一次出门顺路 15–20 家）。
- **数据价值**：评分/推荐语/坐标真实化 → 推荐质量与「就近」体验显著提升；为商家合作（CPS）打样。

## 5. 技术要点（一句话版）

- 前端：Vite 原生 JS（零依赖），主包 gzip 6KB，视图按需加载。
- 后端：自有 Node（:8799），双轨智能体（确定性引擎 + DeepSeek），文件持久化（账号/收藏/券）。
- 视觉：智谱 GLM-4V-Flash 免费多模态（开发 AI 看图 / 未来拍照识店）。
- 部署：Vercel（前端）+ Fly.io 免费层（后端）→ 见 docs/design/free-launch-path.md。
