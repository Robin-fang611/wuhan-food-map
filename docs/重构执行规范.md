## 三、每页必做清单（Common Checklist）

### 3.1 `<head>` 改造

- `viewport` 建议改为：`width=device-width, initial-scale=1.0, viewport-fit=cover`（去掉 `user-scalable=no`，可访问性更好）。
- 删除 `<head>` 内联的 `body{font-family:...}` `<style>` 块。
- 补全 OG 四件套：
  ```html
  <meta property="og:title" content="财大 2026 新生 · 页面标题">
  <meta property="og:description" content="一句话说明本页价值">
  <meta property="og:image" content="https://zuel-freshman.netlify.app/images/og-image.png">
  <meta property="og:url" content="https://zuel-freshman.netlify.app/页面名.html">
  ```
- `<title>` 保持 `江城 · 页面标题`。

### 3.2 `<body>` 属性

在 `<body>` 加 `data-page="模块ID"`，例如：
```html
<body data-page="xinsheng">
```
模块 ID 见上表。

### 3.3 Hero 改造

原 Hero：
```html
<section class="module-hero m-accent">
```
改为：
```html
<section class="module-hero m-accent m-模块ID">
  <div class="mh-icon">emoji</div>
  <h1>页面标题</h1>
  <p>一句话价值</p>
  <button class="share-btn" id="shareBtn" aria-label="分享">↗</button>
  <span class="mh-badge">标签</span>
</section>
```
- 必须加 `.m-模块ID`（如 `.m-xinsheng`），用于模块色。
- 必须加分享按钮 `#shareBtn`；首页不在这加（首页有独立分享入口）。
- emoji 要与主题相关。

### 3.4 群入口改造

找到：
```html
<div class="group-entry" id="groupEntry">
  ...
  <div class="group-entry-title">加入吃喝玩乐群</div>
  <div class="group-entry-desc">扫码进群，和师兄师姐一起探索</div>
  ...
</div>
```
改为统一文案：
```html
<div class="group-entry" id="groupEntry">
  <div class="group-entry-icon">💬</div>
  <div class="group-entry-text">
    <div class="group-entry-title">加入 2026 新生群</div>
    <div class="group-entry-desc">师兄师姐在线答疑，选课/宿舍/社团全搞定</div>
  </div>
  <div class="group-entry-arrow">›</div>
</div>
```

### 3.5 建设中提示

如果某页内容确实还没完全到位，在 Hero 下方加：
```html
<div class="wip-tip">本页内容建设中，先看已有的，更多内容开学前更新。</div>
```
本次 `growth.html` 已加；其他 14 页尽量不加（要求注入真内容）。

### 3.6 滚动揭示

给每个内容块加 `class="reveal"`，例如：
```html
<div class="block reveal"> ... </div>
```
列表行、票根、时间线行也加 `reveal`。动画由 `app.js` 统一驱动。

### 3.7 页脚与脚本

页脚保持：
```html
<div class="footer">江城编辑部 · 与师兄师姐一同修订 · 2026</div>
```
</div> 闭合后必须是：
```html
<script src="js/config.js"></script>
<script src="js/app.js"></script>
</body></html>
```

## 六、git 工作流

1. 开始前先 `git pull origin refactor/handbook-v2`。
2. 只改分配给自己的 HTML 文件。
3. 完成自检后提交，message 格式：
   ```
   refactor(content): <模块ID> 注入真内容并修复页面级增长断点
   
   - 来源：docs/提取/校园生活全攻略.md
   - 改动：xxx.html OG/分享按钮/群文案/脚本链/内容块
   ```
4. 多个文件可一个 commit，但必须是同一子代理负责的文件。
5. **不要 push**，提交到本地 `refactor/handbook-v2` 分支即可；主代理最后统一 push。
