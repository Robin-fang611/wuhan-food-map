# 第 2 轮交互体验优化：内容与可读性

## 本轮目标
解决自动扫描与截图审查中发现的「内容重复感」和「大段文字阅读疲劳」问题，让每页首屏引导更聚焦、正文更适合手机碎片化阅读。

## 问题清单

### P1 · 跨页重复引导标题「先看这一条」
- **现象**：`shenghuo.html` / `shetuan.html` / `sushe.html` 三页第一个内容块都使用完全相同的标题「先看这一条」，用户连续浏览时会产生"内容雷同"的错觉。
- **根因**：内容注入时使用了统一模板，未按页面主题替换。
- **修复方案**：
  - `shenghuo.html` →「食堂先知道」
  - `shetuan.html` →「社团怎么加」
  - `sushe.html` →「宿舍怎么分」
- **验收标准**：三页首屏引导标题不再重复，且与正文强相关。

### P2 · 多个页面存在超过 220 字的长段落
- **现象**：`jiaotong.html`、`jingsai.html`、`shenghuo.html`、`tice.html`、`xiaoqu.html` 部分段落字数在 230–350 字之间，手机上一屏只能看 1–2 段，阅读压力大。
- **根因**：从文档直接复制过来的大段说明未做移动端拆分。
- **修复方案**：保留核心信息，把长段落拆成 2–4 行的短段落，或使用 `<ol>` / `<ul>` / `.check` 步骤化呈现。
- **涉及页面与段落**：
  - `jiaotong.html`：武昌站、天河机场两条地铁路线说明
  - `jingsai.html`：大创、博文杯、挑战杯/互联网+、志愿公益嘉年华的定义段落
  - `shenghuo.html`：瑞膳鱼粉推荐语
  - `tice.html`：测试注意事项
  - `xiaoqu.html`：医保报销材料清单、官方公众号介绍
- **验收标准**：上述长段落全部拆短，单段不超过 5 行；扫描脚本不再报这些段落超过 220 字。

- `handbook/jiaotong.html`

1. `node tools/ux-review.js`：确认无跨页重复标题、长段落数量明显减少
2. `node tools/mobile-check.js`：确认无新增横向溢出
3. WebKit 截图抽查 3 个修改页首屏
