# 第 5 轮：无障碍与可读性优化

> 轮次定位：前四轮分别解决「排版错误 / 内容可读 / 搜索反馈 / 路径闭环」，本轮从「看得清、用得了、搜得到」三个维度做最后一轮体验打磨。

## 问题来源

用新工具 `tools/a11y-check.js`（Webkit 真内核，390×844）扫描 14 页，发现 56 项问题：

1. **对比度不及格**：7 个设计 token 未达 WCAG AA，最严重的是首页目录「壹/贰/叁」仅 1.58:1，次要文字仅 2.87:1。
2. **页面无地标**：全站 14 页没有 `<main>`，也没有跳至正文链接，键盘用户进入页面要先 Tab 过顶部 10+ 个控件才能到正文。
3. **焦点样式缺失**：搜索框 `outline:none`、chip 焦点依赖浏览器默认，深色主题色上几乎不可见。
4. **标题层级跳跃**：`xinsheng.html` 出现 `h1 → h3`，`index.html` 出现 `h1 → h4`。

## 设计决策

### 1. 改色而非改样式
视觉风格已经稳定，最小化改动的做法是只把不达标的 token 加深到刚好满足 4.5:1（大字 3:1），色相/饱和度不变，观感变化最小。

| Token | 原色 | 新色 | 原对比（最差） | 新对比 |
|---|---|---|---|---|
| `--ink-3` 次要文字 | `#948F82` | `#716D61` | 2.87 | 4.59 |
| `--red` 江城红 | `#C54E36` | `#B94933` | 4.13 | 4.59 |
| `.mrow .no` 章节序号 | `#C9C2B0` | `#8C8571` | 1.58 | 3.27 |
| `m-sushe` | `#8A6A4F` | `#86674D` | 4.38 | 4.59 |
| `m-junxun` | `#6B7355` | `#697053` | 4.43 | 4.61 |
| `m-shenghuo` | `#B06A3B` | `#9C5E34` | 3.75 | 4.59 |
| `m-jiangzhu` | `#97722F` | `#89672B` | 3.92 | 4.62 |

### 2. 用 JS 注入无障碍基础设施
14 页结构统一，为避免逐页改 HTML（易改漏），通过 `js/app.js` 统一注入：

- 首屏最前面插入 `<a class="skip-link" href="#jc-main">跳至正文</a>`
- 给 `.app` 添加 `id="jc-main" role="main"`，形成 `<main>` 地标
- 为所有可聚焦元素补 `:focus-visible` 品牌色轮廓（统一体验、替换搜索框 `outline:none`）

### 3. 标题层级补 h2
- 子页：在第一个 `.block` 之前插入视觉隐藏的 `<h2 class="sr-only">本章内容</h2>`，消除 `h1 → h3` 跳跃。
- 首页：把「现在最想知道的 / 开学前必做八件事 / Stage 标题」从 `h4` 提升到 `h2`，这些本就是内容主标题；样式不变（保持当前字号）。

## 预期收益

- 户外/强光下阅读 secondary text 不再吃力（2.87 → 4.59）。
- 首页大序号从「看不清」变成「看得见但不抢戏」。
- 屏幕阅读器和键盘用户能快速进入正文。
- 无障碍体检问题从 56 项降至 0。
