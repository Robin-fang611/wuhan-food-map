# V3.4 校园增长实验框架（Growth Experiment Framework）

> 状态：草稿框架（自动化迭代管家 2026-08-13 产出，待 Robin 拍板落地口径）。
> 红线：不编造数据——凡示例/预估一律标注 `示例` / `estimated`；二维码为占位，非真实可扫；不出现真实个人手机号/微信号（用占位）。
> 目标：把"今天吃啥"做成校园高频习惯（Job = 日常快决策，高频·低介入·校园先行），用可量化实验验证增长假设。

---

## 1. 增长假设（待验证，非结论）

- H1（渠道）：校园 KOL / 班级社群 / 食堂地推 三条线中，**社群转发**的单客获取成本（CAC）最低、留存最高。
- H2（钩子）：以"今天吃啥？问蛮有味"为统一记忆点，比"美食推荐 App"点击率高。
- H3（留存）：首次使用即领券 + 7 天签到，次日留存显著高于无激励组。
- 以上为**假设**，框架给出验证方法；结论由实验数据回填，不预写。

## 2. 三条获客渠道（Campus-first）

| 渠道 | 载体 | 触达场景 | 二维码去向 | 风险/红线 |
|------|------|----------|------------|-----------|
| KOL | 校园达人图文/短视频（示例：小吃测评、探店 vlog） | 小红书/抖音/校园号 | 主页/评论区占位 | 达人素材需真实，禁用伪造探店 |
| 社群 | 班级群/宿舍群/老乡群转发 + 新生群置顶 | 群聊、迎新季 | 群公告占位 | 不买粉、不刷量；文案不夸大疗效 |
| 地推 | 食堂/宿舍/图书馆海报 + 摊位扫码 | 线下高频动线 | 海报占位 | 二维码为占位，上线后由后台生成 |

> 二维码统一为**占位框**：`【扫码占位 · 上线后由增长后台生成真实码】`。在域名/上线地址确定前，不生成任何真实可扫二维码（避免指向未部署/未授权地址）。

## 3. 转化漏斗（与现有埋点 EVENTS 一一对应）

`analytics.js` 已埋以下行为事件（§9，全部非 PII、聚合计数）：

```
[今天吃啥频次] APP_OPEN  ──►  SEARCH(今天吃啥问句)  ──►  DETAIL_VIEW(看一家)
      │                                                  │
      └──────────────►  NAV_CLICK(导航到店)  ──►  FAVORITE(收藏)
                                                 └──► CLAIM(领券) ──► COUPON_REDEEMED(核销)
```

- **今天吃啥频次**定义（可量化、可观测）：当日 `APP_OPEN` 次数 = 当日"今天吃啥"决策时刻数；当日 `SEARCH` 次数 = 当日主动决策查询数。两者并列观测（见看板）。
- 漏斗各层计数 = 对应事件名累计（看板自动汇总，无需新埋点、不新增 PII 字段）。

## 4. 实验设计（A/B，最小可行）

- 变量：仅改**文案钩子**（H2），其余不变。A 组="今天吃啥？问蛮有味"；B 组="校园美食 AI 推荐"。
- 指标：扫码转化率（到店/到 APP_OPEN）、次日留存、7 日留存。
- 判定：`estimated` 门槛——单组样本 ≥ 200 次曝光再下结论；结论回填本表，禁止用小数样本下绝对结论。
- 分群：按渠道分组（KOL/社群/地推）分别统计，避免混样。

## 5. 度量与看板（埋点看板 = `growth-dashboard.js`）

- 入口：账号中心 → "增长看板（内部·v3.4）"（与"商家核销台"同级，内部工具）。
- 展示：`今天吃啥频次`（今日 APP_OPEN / 今日 SEARCH）、DAU（今日不同 vid 的 APP_OPEN）、搜索热词 Top、全量漏斗计数。
- 数据来源：本地 `analytics` 缓冲（`getQueue()`），纯前端聚合，**不向任何外部上报**（reporter 默认 no-op，红线 §8/§9）。
- 上线后：BFF 接入只需替换 `analytics.reporter`，看板与调用方零改动。

## 6. 成功门槛（建议，待 Robin 确认）

| 指标 | 起步门槛（estimated） | 备注 |
|------|----------------------|------|
| 单渠道 CAC | < ¥2 / 激活用户 | 校园低 ARPU，需极低成本 |
| 次日留存 | > 30% | 高频习惯型产品基准 |
| 7 日留存 | > 15% | 签到+领券激励后 |
| 核销率 | 得券→核销 > 8% | 连接 CPS 变现（V4） |

> 以上数值为**行业经验占位（estimated）**，非本产品实测；真实门槛由实验数据回填。
