### 2.1 子页进群按钮复活（最大断点）

**根因**：`baibaoxiang.js` L21 注释"群入口已迁移至 js/pages/index.js"，但 `index.js` 只被首页加载（`index.html` L111），**15 个子页的 `#groupEntry` 无任何 JS 绑定 → 点击无反应**。

**改法**：在 `js/baibaoxiang.js`（子页与首页都加载）末尾补绑定：

```js
// 群入口 — 全局统一走社群弹窗（修复子页死按钮）
var groupEntry = document.getElementById('groupEntry');
if (groupEntry) {
  groupEntry.addEventListener('click', function () {
    showSocialModal();  // 定义见 js/core/ui.js（ES module）
  });
}
```

> **注意**：`showSocialModal` 在 `core/ui.js` 是 ES module 导出，而 `baibaoxiang.js` 是普通 script。实施时二选一：
> - **方案 A（推荐）**：`showSocialModal` 复制一份为全局函数进 `baibaoxiang.js`（与现有 `showAdPopup` 双实现并存，短期可行）；
> - **方案 B（更干净）**：新建 `js/app.js` 普通 script 放全站通用绑定（群入口/返回/手风琴/分享按钮），子页 script 链改为 `config.js → baibaoxiang.js → app.js`（`app.js` 内嵌 `showSocialModal` 实现）。**推荐 B，一步到位，P1 底部栏也放这**。

## 五、P1 · 体验升级

### 5.1 全局搜索（改版计划修正版）

**决策**：放弃"构建期生成 search.json"（与无构建步骤矛盾）与"运行时 fetch 16 页"（要处理 gate/分词）→ **手工维护 search.json + 前端模糊匹配**：
- 一次性本地脚本（python/node）从 16 个 HTML 抽取标题/正文段落 → 生成 `search.json`（章节名、页面路径、关键词、场景标签、摘要片段）→ **提交进仓库**。以后每次内容更新重跑一次（几秒）。
- 前端：搜索框（首页顶部 + 底部栏）→ fetch `search.json` → 前缀/子串模糊匹配（含场景标签）→ 命中列表点选直达。
- 无外部依赖、无构建步骤、不破坏拖拽部署。
- **验收：搜索能命中全部 16 页关键词。**

### 5.2 底部常驻栏

- 子页常驻底部 tab：首页 / 搜索 / 进群（3 项），JS 注入（`app.js` 动态生成，改一处管 16 页）。

## 七、验收标准（改版计划修正版）

1. **内容正确性**：无 404 链接（全站 link 扫描）；无 2024 级时效硬伤；群文案统一"2026 新生群"。
