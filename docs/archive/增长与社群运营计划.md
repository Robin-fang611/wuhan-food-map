# 增长与社群运营计划

> 核心假设：手册是钩子（有用 → 分享 → 进群），社群是资产，美食地图是社群内的二次传播与未来变现。
> 本文把"引流建社群、再做美食地图"落成可执行的打法。

## 一、增长飞轮

**手册（有用且可分享） → 新生进群 → 群内沉淀关系与信任 → 美食地图在群内自然传播 → 真实流量 →（未来）商家愿意付费**

## 二、9 月窗口时间线

- **现在 – 8 月底**：手册改版上线；准备分发物料（分享话术、群二维码、海报）；学生合伙人就位。
- **8 月底 – 报到前**：通过已有宣传方法（公众号 / 树洞 / 新生群）铺手册链接；合伙人进各院新生群发"民间手册"。
- **报到周（约 9 月初）**：手册搜索 / 进群峰值；群矩阵放量；收集首批反馈。
- **第一学期**：社群常态化运营；美食地图数据接入并在群内推。

## 三、学生合伙人怎么用（"有人"路径）

- **内容 BD**：补充本院 / 本专业知识，让手册更准。
- **分发 BD**：进新生群发手册、拉人进群。
- **群运营**：答疑、维护氛围、收集选题。
- 不要求合伙人做地推商家（商家变现后置）。

## 四、已有宣传方法（复用，不新建）

- 公众号推文挂载手册链接。
- 校内树洞 / 墙分发。
- 各学院新生群矩阵。
- 学长学姐朋友圈转发（前提：手册本身要"值得转"）。

## 五、社群运营要点

- **群矩阵**：按学院 / 校区分群，避免大群沦丧。
- **内容节奏**：每周 2–3 条手册更新 / 答疑精华。
- **从手册到美食地图的引流**：手册群入口常驻；美食地图上线后在群内以"周边吃什么"话题自然引入。
- **防流失**：群内持续给价值（答疑、资料、避坑），不只是发广告。

## 六、指标（看手册是否真有用）

- **手册**：曝光 / 点击（PV / UV）、进群率（看群入口转化）、分享率（看转发）、留存（次日 / 7 日回访）。
- **社群**：建群数、群活跃、美食地图在群内的点击。

## 七、变现后置

商家付费放在"社群与美食地图已有真实流量"之后。届时按架构方案起 BFF，做商家入驻 / 优惠券 / 核销闭环。现在不做。
