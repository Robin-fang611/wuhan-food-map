# 第 1 轮交互体验优化

## 本轮目标
修复用户在微信真机截图中直接指出的两个显性问题，并建立可复用的「找问题→写文档→实现→验证」循环模板。

## 问题清单

### P0 · 奖助学金页 `.check` 排版错乱
- **现象**：`jiangzhu.html` 顶部的 3 条勾选提示在小屏下换行异常，`<b>` 高亮文字被当作独立 flex item 换到下一行并右移，出现"家庭经济困 / 难认定"被拆开的破碎排版。
- **根因**：`.check` 使用 `display: flex`，其直接子节点包含 text node 与 `<b>` 元素；在 flex 布局中，text node 会被匿名包裹成 flex item，空间不足时 `<b>` 作为独立 flex item 换行，破坏语义。
- **修复方案**：把 `.check` 从 flex 改为 `position: relative; padding-left: 27px;`，`.box` 改为 `position: absolute; left: 0; top: 11px;`，让文字按正常 inline 流排列，`<b>` 仅作为语义高亮。
- **验收标准**：在 iPhone SE（375px）与 WebKit 真内核下，3 条 `.check` 文字均不再出现断词错位，box 与第一行文字视觉居中对齐。

### P1 · 奖助学金内容块序号重复
- **现象**：`jiangzhu.html` 中出现多个"块二"，把用户搞混（政府奖学金→块一、校设奖学金→块一、外设奖学金→块一、国家助学金→块二、国家助学贷款→块二、勤工助学→块二、学费减免→块二、困难补助→块二）。
- **根因**：内容注入时直接复制了标题模板，未按顺序递增编号。
- **修复方案**：按内容逻辑重新编号为块一到块八。
  - 块一 · 政府奖学金
  - 块二 · 校设奖学金
  - 块三 · 外设奖学金
  - 块四 · 国家助学金
  - 块五 · 国家助学贷款
  - 块六 · 勤工助学
  - 块七 · 学费减免
  - 块八 · 困难补助
- **验收标准**：页内所有 `h3` 块标题无重复编号，顺序正确。

## 影响范围
- `handbook/css/baibaoxiang.css`：`.check` / `.box` 样式重构
- `handbook/jiangzhu.html`：块标题重新编号

1. 本地 `python3 -m http.server 8899`
2. `node tools/mobile-check.js`：确认无横向溢出、无小触控目标
3. `node tools/e2e-check.js`：确认全站功能链路通过
4. WebKit 截图 iPhone SE 375×667 下 `jiangzhu.html` 首屏
