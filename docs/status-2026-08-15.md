## 七、线上 Bug 修复（2026-08-15 实查 · 收到「连不上 Agent 后端」反馈）

**症状**：线上（http://47.102.141.67:8080）对话页点「心情不好 / 想省钱」或输入问句后报「暂时连不上 Agent 后端」。

**根因 1（主）**：`hypha/integration/agent-client.js` 把 LOCAL_AGENT/SERVER_AGENT 硬编码为 `http://127.0.0.1:8799`，绕过了 `VITE_API_BASE` 配置（生产构建为 `/api` 同源反代）。用户在浏览器打开线上站点时，前端实际请求的是**用户自己电脑**的 8799 端口 → 必然连接失败。auth/explore 等模块都正确走 `apiBase`，唯独 Agent 聊天链路漏了。

**根因 2（潜伏）**：`/run` 后端有 25s LLM 升级护栏（httpServer.js），前端 `discover()` 超时却只有 15s → 健康语义/模糊表达触发 DeepSeek 升级时（实测「清淡的健身餐」线上耗时 9.97s），响应一旦超过 15s 会被前端提前 abort，误报「连不上」。
另修复 3 处面向用户文案里的 `:8799` 端口提示（线上用户看到会困惑）。

**修复**（commit 见 git log）：
- agent-client.js：基址改为运行时读 `__MANYOUWEI_CONFIG__.apiBase`（浏览器），Node 兜底 `http://127.0.0.1:8799`；`discover()` 超时 15s→30s。
- reasoning.js：3 处用户文案去除 `:8799`/运行命令提示，改为友好话术。

**验证**：65/65 测试全绿；node --check 通过；生产模式构建（VITE_API_BASE=/api）产物确认 agent 分块改读运行时配置；线上 `/api/run`、`/api/agent` 反代实测 200 且真跑 DeepSeek。**已部署阿里云**（2026-08-15 Robin 确认）：h5/dist 上传 + pm2 restart manyouwei-web，线上对话实测「心情不好」→ 主推 m0448（hypha-react 升级，10s < 30s 前端超时）。另给 vite.config.js 加 preview 代理（剥 /api 前缀，与 static-server 行为一致），本地预览按 h5/.env 构建后本地点对话不再 404。
