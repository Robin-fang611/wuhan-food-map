# 新生手册 · 前端体验改版计划

> ⚠️ **已替代**：本文为初版草案（2026-08-03），已被《手册重构实施计划.md》取代（含 4 方向审计、P0/P1/P2 分级、文件级改动清单）。保留存档，勿再作为执行依据。

## 一、现状评估（基于已读代码）

**已有的好底子：**
- 完整设计系统 `css/baibaoxiang.css`：「编辑部 / 手账」气质，江城红单色强调，宋体标题 + 楷体批注，圆角收敛，移动端 460px 居中。
- 组件齐全：封面、四阶段时间线、模块列表行、师兄师姐批注、群入口、模块页 Hero、内容区块、FAQ 手风琴、清单勾选。
- 已有 OG 标签、解锁弹窗、开屏二维码等增长雏形。

**明显短板（直接拉低"愿意用 / 愿意分享"）：**
- **无搜索**：16 页内容靠首页逐层点，找不到东西就走。
- **无跨页导航**：进子页后只能返回首页，翻页靠手动改 URL。
- **无分享**：每页没有"发给同学"入口；OG 图有但分享卡片未优化。
- **内测锁**：Stage 04 七页带内测锁 / 置灰，反而劝退传播。
- **无留存钩子**：看完即走，没有收藏 / 进度 / 再来。
- **视觉**：间距层级尚可，但缺微动效与一致的图标 / 插图语言，首页转化力弱。

## 二、改版目标

1. 新生**进得来、找得到、愿意看完**。
2. 看完愿意**分享给同学 / 进群**。
3. 视觉与服务号级产品看齐，去掉"个人站"的廉价感。

## 三、具体改版项（按优先级）

### P0 · 立即可做，不动内容结构
- **全局搜索**：顶部搜索框，本地索引 16 页正文，输入即筛章节 + 命中片段。纯前端（构建期生成 `search.json` 索引）。
- **底部快捷栏**：子页常驻底部 tab（首页 / 搜索 / 进群），解决"进子页就迷路"。
- **每页分享按钮**：唤起系统分享 / 复制链接，配优化后的 OG 图（标题含"财大 2026 新生"）。
- **进群常驻入口**：群入口从页面底部提到常驻（底部栏或悬浮），提升进群率。
- **弱化内测锁**：要么全开放（推荐，利于传播），要么改为"内容建设中"轻标记，不再置灰拦截。
- **首页增强**：加社会证明（"已有 X 位新生在用"，可用估算 / 占位）、强化"加入新生群"主 CTA、首屏一眼看懂"这是干嘛的"。

### P1 · 视觉与交互打磨
- **间距与层级**：统一 8px 栅格，标题 / 正文 / 注释三级对比更清楚。
- **微动效**：页面切换淡入、列表入场错峰、滚动揭示；现有 `:active` 按压反馈保留并补充。
- **图标 / 插图语言**：统一 emoji 或精简线性图标，避免混搭；关键页加 1 张手绘风插画。
- **卡片质感**：轻阴影 + 细分隔，减少大块描边带来的沉重感。
- **字体节奏**：正文行高 1.8、段距、首行不缩进，更利于手机阅读。

### P2 · 留存与增长钩子
- **收藏 / 进度**（localStorage）：Checklist 可勾选并记住；"我的必读"清单。
- **内容更新提示**：顶部小条"X 月 X 日更新了军训岗攻略"。
- **每页结尾引流**："这份有用？发给同专业同学" + 群入口。

## 四、验收标准

- 任意内容 **3 次点击内可达**；搜索能命中全部 16 页关键词。
- 任意子页可在 **1 次点击**回到首页 / 搜索 / 进群。
- 每页有分享入口，分享卡片标题正确。
- 视觉达到"不像个人站"的整洁度（由 Robin 主观确认）。

## 五、技术约束

- 纯静态，无构建步骤，保持 Netlify 直接部署。
- 不引入框架；搜索索引用一个小脚本从 16 个 HTML 抽取生成 `search.json`。
- 现有 CSS 变量体系保留并扩展，不在页面写死样式。
