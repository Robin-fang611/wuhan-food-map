军训攻略

必备清单 · 军训联络员 · 战地记者 · 报名面试全流程

师兄经验

军训必备 · 防暑降温

武汉的秋老虎不是开玩笑的，军训第一周中暑的同学每年都有。下面这份清单是师兄师姐实地踩过坑整理的，按重要度排序。

  1. 水杯 + 淡盐水：届时学校会统一发放大杯子，几百人一个样式，强烈建议提前备好姓名贴，否则休息时根本找不到自己的杯子。杯里兑一点淡盐水补电解质，比纯水更抗晒。
  2. 藿香正气水 / 胶囊：专治轻度中暑，怕苦的直接买胶囊剂型，一板揣兜里。
  3. 清凉喷雾：一次大约能撑 2 小时。注意喷帽檐、衣领，不要直接喷在皮肤上。
  4. 清凉油：提神醒脑，头发晕的时候抹太阳穴；被蚊虫叮咬也能应急。
  5. 冰凉贴：休息期间贴额头降温防中暑，一盒基本够用一周。
  6. 手持小风扇：间歇休息时驱散热意，选容量大、能挂脖的款式，解放双手。
  7. 止汗露：早上出门涂一次能清爽一整天，还能顺带驱蚊防蚂蚁。

军训必备 · 防晒与晒后修复

  1. 防晒霜 / 防晒喷雾：认准高倍数、防水防汗，按自己肤质挑。建议再装一瓶分装版揣兜里，军训休息间隙随手补涂。
  2. 帽子：军训物资会统一发放帽子，注意妥善保管，弄丢了补办很麻烦。
  3. 冰袖：物理防晒最管用；露在外面的手指、手背也别忘了涂防晒。
  4. 芦荟胶：晒后修复的好帮手，每晚回寝厚敷一层，第二天不容易脱皮。
  5. 补水面膜：经历一整天暴晒后皮肤极度缺水，睡前敷一片。

军训必备 · 其他容易忘的小东西

  1. 软鞋垫：站军姿一站就是半小时起步，一副舒适的软鞋垫能明显缓解脚后跟疼。
  2. 湿纸巾：擦汗、清洁、消暑，随身装一小包。
  3. 驱蚊液：适用于只穿短袖不穿外套的情形，出门前涂手腕、脚腕。
  4. 皮筋 / 黑色一字夹 / 腰带：女生扎头发、夹碎发、避免衣物不服帖；军训裤普遍偏大，腰带必带。
  5. 耳棒：军训不允许佩戴太显眼的耳饰，刚打耳洞的萌新可以戴耳棒防止耳洞闭合。
✎ 师兄踩坑军训物资（帽子、皮带、徽章）一定要妥善保管、当天带齐。忘带就得跑回寝室拿，一来一回耽误的是整个连队的进度。

为什么要了解这两个岗位

军训期间有两个值得关注的特殊岗位：军训联络员和战地记者。前者是新生接触到的第一个正式学生工作岗位、班委竞选的重要跳板；后者是「免训」高性价比岗位，无需参加连队训练，军训评分普遍 90 分以上。

✎ 师兄提醒若有意竞选班长 / 团支书，优先冲联络员；若只想拿高分、避开高强度训练，强烈推荐战地记者。

军训联络员 · 岗位速览

  1. 岗位定位：军训期间的临时班委，充当同学与辅导员 / 教官之间的桥梁，是后续正式班委选举的重要跳板。
  2. 主要职责：集合点名、照顾伤病同学、协助辅导员处理事务（如组织体检集合）、传达各类通知、管理班级日常事务。
  3. 三大核心优势：① 快速认识班级同学，融入更快；② 与辅导员建立良好联系，对参与学生组织和评奖评优有帮助；③ 军训分数有额外加成（教官打基础分，导员按表现加分），并积累学生工作经验。

联络员 · 报名流程

  1. 关注通知：招募通知一般在报到前后由院系 QQ 群发布（具体时间以学院通知为准）。拿到录取通知书后就尽早加入院系群和企业微信，别错过窗口。
  2. 填写报名表：按要求填写后发送至指定邮箱，重点打磨「主要事迹」和「自我评价」。
  3. 面试：开学前多为线上（腾讯会议，一对一或群面）；开学后可能线下，形式因学院而异。
  4. 公示：面试后很快出结果，通常当晚或次日早上公布名单。

联络员 · 报名表怎么写

  1. 主要事迹：突出初高中班干部经历、班级管理经验（学生会 / 志愿服务）、荣誉奖项、活动组织经验。
  2. 自我评价：展现性格特点、语言沟通能力、摄影 / 推文等技能、管理与组织能力。
字数不设上限，建议尽量写充分——既体现诚意，也让面试官对你有更全面的了解。

联络员 · 选拔看什么

服务意识（首要，摒弃「官本位」）抗压能力班级管理经验（班长 / 团支书 / 课代表）沟通协调能力责任心 · 通知传达不遗漏应变能力（天气 / 物资 / 突发状况）关键时刻不掉链子
面试常见问题：① 过往班干部经历、任职时长、所获荣誉与师生评价；② 对联络员岗位的认识、报名原因；③ 遇到突发情况如何解决。

战地记者 · 岗位速览

  1. 免训福利：独立于连队之外的宣传岗位，不参加连队训练，无需烈日下站军姿走方阵，大部分时间在室内或阴凉处采编。
  2. 高分保障：属政治部编制，评分由政治部老师直接评定，普遍 90 分以上；以脑力劳动为主，工作节奏紧凑但体力消耗小。
  3. 履历产出：推文与照片发布于学校官方军训专题平台，并收录于军训纪念册，形成可展示的成果。

战地记者 · 报名三步走

  1. 盯紧班群通知：一般在军训开始前 1–2 周发布（具体时间以学院 / 班群通知为准），报名窗口仅 3–5 天，提前把个人简介准备好。
  2. 报名表筛选：考察四个维度——个人特长（摄影 / 写作 / 采访经历）、设备情况（自备器材是加分项）、时间保障、对宣传工作的态度。报名表直接决定学院是否推荐，务必认真填。
  3. 面试录取：单人面试，面试官通常是政治部老师，时长仅几分钟，需在短时间内展现优势。
设备一般自带（相机 / 无人机），有设备会优先考虑；没有专业设备也别放弃——录取后不一定分到摄影岗，可主打文稿或采访方向。

战地记者 · 三大方向选哪个

  1. 📷 摄影岗：需构图用光基础、能抓拍新闻瞬间与人物特写，最好自备器材并会基础修图。技巧：队列方阵找角度、拉歌抓情绪、内务细节显真实。适合有摄影基础和设备的同学。
  2. ✍️ 文稿岗：需扎实文字功底与快速成稿能力，适应每日发稿节奏；可借助 AI 辅助撰写推文。建议提前研读往届军训专题、准备 2–3 个选题思路。适合文笔好的同学。
  3. 🎤 采访岗：对接教官与学员，需亲和力、善于提问引导、快速整理素材。面试加分项：准备军训相关采访选题与模拟采访提纲。适合沟通能力强的同学。

战地记者 · 面试怎么打动老师

自信表达 · 眼神交流 · 逻辑连贯用具体案例代替空泛描述携带过往作品佐证明确三大方向中的自我定位场景题展示专业思维（怎么拍 / 怎么写 / 怎么采）强调服从纪律与团队协作
「我曾负责 XX 活动拍摄」远比「我喜欢摄影」有说服力。可以适度润色经历、突出优势，但不建议编造完全不存在的能力——面试被追问细节容易露馅。
